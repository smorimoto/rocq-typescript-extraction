# Submodules

`compcert` and `fiat-crypto` are git submodules pinned for `test/compcert` and `bench/fiat-crypto`. `dune` marks them vendored and includes the two manifests, so only the files a manifest selects are built.

- `compcert.dune` and `fiat-crypto.dune` are generated by `test/compcert/gen-dune.ts` and `bench/fiat-crypto/gen-dune.ts`. Do not edit them; `dune test` diffs each against a fresh run of its generator.
- Upstream sources and proofs are never modified. Generated programs stay under `_build` and are not installed with the plugin.
- `compcert.dune` copies only the audited LGPL subset with x86-64 parameters fixed, and the generator rejects anything outside it. Licensing notes live in `test/compcert/README.md` and `bench/fiat-crypto/README.md`.
- Initialise with `git submodule update --init --recursive --depth 1`; Fiat Crypto's nested Rewriter submodule is required too.
